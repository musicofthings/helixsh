Guardrails at every boundary

A desktop UI that does not become a shell.

The renderer has no Node.js access and cannot submit arbitrary commands. Every request crosses a narrow, validated interface in the main process.

  • 01
    Sandboxed rendererContext isolation, strict content policy, no popups or navigation.
  • 02
    Validated execution planThe exact plan must pass before the native Run confirmation appears.
  • 03
    Deterministic boundaryFixed argument arrays, no arbitrary shell input, and auditable POSIX execution.
